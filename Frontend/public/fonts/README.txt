# Carpeta de Fuentes Locales (CS Ristela)

Para utilizar tu archivo de fuente original de **CS Ristela**:
1. Copia tu archivo de fuente aquí con alguno de los siguientes nombres:
   - `CSRistela.otf`
   - `CSRistela.ttf`
   - `CSRistela.woff2`
   - `CSRistela.woff`

El sistema cargará automáticamente tu archivo de fuente con prioridad máxima sobre los respaldos web.
